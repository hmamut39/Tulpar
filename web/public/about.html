About

Tulpar was created by Mamuti Aishan (Hasan).

A tool for front-end developers who build with a design system and are tired of AI code that only looks right.

Why Tulpar exists

Most AI tools turn a design into code that resembles the picture. In a real product that is not enough: the code has to use your team's own components and tokens, and it has to actually match the design. Tulpar writes the component with your design system, then builds it, renders it in a browser, runs its tests and compares it with the design before you see it. If something fails, it repairs it; if something can't be checked, it says so.

What it supports

React, Vue, Angular, Svelte, Web Components, Flutter, Blazor (C#) and Leptos (Rust), with Carbon, Material UI, Chakra UI, Radix Themes, shadcn/ui, PrimeNG, Element Plus and Shoelace built in, and any design system on npm added from the page. It works on the web, from the command line, in VS Code, and in AI coding assistants through MCP.

The name

Tulpar is the winged horse of Turkic legend: a strong, fast horse that carries its rider where they need to go. The site lives at tulparsi.com.
